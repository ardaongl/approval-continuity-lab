M1 may bootstrap the approved tools/virtualenv only after build authorization; M0 may run lightweight read-only capability probes and documentation checks, never silently install missing dependencies. Estimated effort remains a rough showcase budget, not a deadline. If M0 finds the runtime unavailable, report the exact interpreter/capability blocker and preserve contracts.

Every milestone records command, exit, expected result, observed result, environment, candidate fingerprint, timestamp and evidence reference under ignored .local-verification/. Distinguish expected nonzero child commands from failing test runner exits. No required product gate may use metadata-only validation as proof.

Future authorized Goal objective: implement v0.1.0 through M1–M6 to LOCAL_READY under GOAL/AGENTS/docs, run every local AC, preserve scope/limits/frozen oracles, and stop with hosted pending and no remote changes. Only create a Codex Goal if explicitly authorized and supported; otherwise ordinary bounded prompts can perform the same build. Do not start one during spec.

After narrow blocker remediation, use factory targeted re-preflight: prior repro → changed contract/dependencies → preserved invariants → fresh relevant checks. Core semantic/schema/platform changes require full independent M0. Never repeat market research for a bounded local correction unless differentiation itself changed.
